# os_phone

Systeme KIT complet pour ComputerCraft (CC:Tweaked) : serveur + telephone (PIL OS) + bornes ATM + console admin.

## Installation du serveur

Sur un ordinateur neuf en jeu (Advanced conseille, avec un Ender Modem) :

```
wget https://raw.githubusercontent.com/KingofNil/os_phone/main/install-all.lua install-all
install-all
```

L'installateur demande le mot de passe admin et la cle API V-SMP au clavier
(rien n'est stocke dans le fichier), ecrit tous les fichiers puis redemarre
sur le serveur.

Ensuite : telephones / ATM / console admin s'installent depuis le serveur
(voir le README.txt installe a la racine).
